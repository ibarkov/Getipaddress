# Get IP

A simple console application written in C# that gets the IP address of a host by its domain name.

A compiled executable is available in the repository:

GetIP.exe — just download it and run it in a console (Command Prompt / PowerShell). No installation required.

Pass the domain name as a positional argument, without any flags:

GetIP.exe google.com

An early .NET networking project, no longer actively maintained.
